Text inside script and style elements is ignored. br elements are returned as newline characters. Configuration Selector - CSS selector for the source element. Multiple type - Choose First Record Only, Multiple Records in Multiple Columns or Multiple Records in One Column. Column count - Number of output columns when multiple values are split across columns. The default is 5. Multiple-value behavior First Record Only: returns the first matching value. Multiple Records in Multiple Columns: returns values across the configured number of columns. Multiple Records in One Column: joins matched text values in one column using two newline characters. Recommended use For a page with one record, create one Text selector per field and return one value. For repeated items with several fields, place the Text selectors beneath an Element selector rather than enabling multiple output on every field.
