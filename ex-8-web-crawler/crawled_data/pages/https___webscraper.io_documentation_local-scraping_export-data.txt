Open the export panel. Select CSV or XLSX where available. Save the file. Open the file and verify encoding, columns and row count. System columns Exports can include Web Scraper system fields such as the source start URL and record order. Retain these fields when they are useful for traceability or downstream joins. Large or repeated exports Use Web Scraper Cloud when data from multiple scraping runs should remain available for download, be accessed through an API, or be delivered automatically to an external destination.
