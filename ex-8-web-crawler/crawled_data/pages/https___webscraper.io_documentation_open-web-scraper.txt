Click the Web Scraper icon in the top-right corner of the browser. If the Web Scraper icon is not pinned, click the browser Extensions icon and select Web Scraper. The Sitemap Wizard opens for the current website. Open the Advanced Sitemap Builder Open the website where scraping should begin. Open browser Developer Tools. Select the Web Scraper tab.
