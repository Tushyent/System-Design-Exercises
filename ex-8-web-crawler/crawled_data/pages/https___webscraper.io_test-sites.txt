Test Sites Here are some test sites that you can use for training while learning how to use the Web Scraper extension. Test site with pagination links Test site with multiple categories, subcategories. Standard links are used for pagination. Test site with load more button Test site with multiple categories, subcategories. Instead of using pagination this site uses a load more button to load more items. Test site that loads items while scrolling Test site with multiple categories, subcategories. Instead of using pagination this site loads items when user scrolls the page down. Test site with log-in Test site with multiple categories, subcategories. In order to access this site, the user needs to be logged in.
